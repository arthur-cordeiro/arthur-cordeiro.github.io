Política de Privacidade

Aplicativo Vídeos. Última atualização: 8 de outubro de 2026.

O Vídeos é um aplicativo de uso exclusivamente pessoal, utilizado apenas pelo seu desenvolvedor, Arthur Cordeiro, para assistir aos próprios vídeos privados.

Dados acessados

O aplicativo solicita acesso somente leitura ao Google Drive da conta autenticada, com a finalidade única de listar e reproduzir os arquivos de vídeo armazenados nela. Nenhum arquivo é criado, alterado ou excluído.

Uso e armazenamento

Os arquivos são lidos sob demanda e podem ser mantidos temporariamente em cache no computador local do próprio usuário. Os dados não são enviados a servidores de terceiros, vendidos, compartilhados ou usados para publicidade.

Uso de dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Revogação de acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Contato
